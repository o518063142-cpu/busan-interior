## 계산 규칙

- 선택한 도배·바닥은 각각 하나만 합산한다. 기존 유지에는 항목을 생성하지 않는다.
- 욕실별로 덧방/전체철거+방수/방수만 중 하나를 고른다. 전체철거+방수에 별도 방수·철거 단가를 재가산하지 않는다.
- 욕실 유지 또는 방수만 상태에서는 타일 업그레이드를 합산할 수 없다.
- 신발장 교체와 방수만 시공은 미확인 항목으로 저장한다. 샤시 범위와 필름 수량은 아래 v2 공개표에 일치할 때만 참고 금액을 합산하며, 규격과 현장 추가비는 확인 대상으로 남긴다.
- 가격 항목이 없으면 소계는 null이다. 0원 공사나 계산 완료로 표시하지 않는다.
- 모든 결과는 totalIsComplete=false, VAT source_unverified다. 확인이 필요한 추가비·원문 범위를 고객 화면에 함께 표시한다.
- 고객 선택은 즉시 계산한다. 접수할 때 API가 같은 공개 기준으로 재계산하며 클라이언트에서 보낸 소계는 신뢰하지 않는다.
- 상담에는 선택값·원본 ID·기준 버전·금액·미확인 항목이 저장된다. 카카오에는 선택 요약을 전달한다. 이메일은 보류 상태다.

## v6 · 공간별 몰딩 선택으로 교정 (현재 기준)
거실·주방·복도·방1~6을 사용자가 선택하고, 각 공간의 천장 몰딩과 걸레받이를 분리한다. 각 부위는 기존 유지/교체/필름/철거 후 몰딩 또는 걸레받이 없이 마감 검토/상담 후 결정 중 하나만 선택한다. 시공 길이는 미터 단위의 선택 입력이며, 미입력은 null로 보존한다. 길이는 각 부위의 시공 길이이고 방 둘레를 두 부위에 자동 복사하지 않는다. 선택을 해제하면 해당 공간 정보를 제거하고, 유지 전환 시 길이를 지운다.
이전 v5의 방 개수별 전체 예시는 거실·주방·복도 포함 범위가 충분히 확인되지 않았으므로 현재 계산에서 전부 합산을 중단한다. 상단도 포함한다. 이를 공간별·미터당·방당 단가로 배분하지 않는다. 마루 동시시공 여부와 관계없이 새 공간별 몰딩은 pending으로 남기며 미확인 금액을 0원으로 표현하지 않는다. 전체 목공 공사가 포함되는 것으로 표현하지 않는다.
기존 저장 상담과 스냅샷은 변경하지 않는다. 이전 버전 선택이 재계산 요청으로 오면 원래 범위·방 개수는 legacyReference에 남기고 공간별 범위 재확인을 안내한다. 새 선택과 예전 전체 예시가 섞인 입력은 거부한다. 출처 URL은 원문 재확인용으로 유지하고 공간별 가격 근거로 사용하지 않는다.
