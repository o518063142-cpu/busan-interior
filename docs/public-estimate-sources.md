- 선택한 도배·바닥은 각각 하나만 합산한다. 기존 유지에는 항목을 생성하지 않는다.

- 욕실 유지 또는 방수만 상태에서는 타일 업그레이드를 합산할 수 없다.
- 신발장 교체와 방수만 시공은 미확인 항목으로 저장한다. 샤시 범위와 필름 수량은 아래 v2 공개표에 일치할 때만 참고 금액을 합산하며, 규격과 현장 추가비는 확인 대상으로 남긴다.
- 가격 항목이 없으면 소계는 null이다. 0원 공사나 계산 완료로 표시하지 않는다.
- 모든 결과는 totalIsComplete=false, VAT source_unverified다. 확인이 필요한 추가비·원문 범위를 고객 화면에 함께 표시한다.
- 고객 선택은 즉시 계산한다. 접수할 때 API가 같은 공개 기준으로 재계산하며 클라이언트에서 보낸 소계는 신뢰하지 않는다.
- 상담에는 선택값·원본 ID·기준 버전·금액·미확인 항목이 저장된다. 카카오에는 선택 요약을 전달한다. 이메일은 보류 상태다.
