## 계산 규칙

- 선택한 도배·바닥은 각각 하나만 합산한다. 기존 유지에는 항목을 생성하지 않는다.
- 욕실별로 덧방/전체철거+방수/방수만 중 하나를 고른다. 전체철거+방수에 별도 방수·철거 단가를 재가산하지 않는다.
- 욕실 유지 또는 방수만 상태에서는 타일 업그레이드를 합산할 수 없다.
- 신발장 교체와 방수만 시공은 미확인 항목으로 저장한다. 샤시 범위와 필름 수량은 아래 v2 공개표에 일치할 때만 참고 금액을 합산하며, 규격과 현장 추가비는 확인 대상으로 남긴다.
- 가격 항목이 없으면 소계는 null이다. 0원 공사나 계산 완료로 표시하지 않는다.
- 모든 결과는 totalIsComplete=false, VAT source_unverified다. 확인이 필요한 추가비·원문 범위를 고객 화면에 함께 표시한다.
- 고객 선택은 즉시 계산한다. 접수할 때 API가 같은 공개 기준으로 재계산하며 클라이언트에서 보낸 소계는 신뢰하지 않는다.
- 상담에는 선택값·원본 ID·기준 버전·금액·미확인 항목이 저장된다. 카카오에는 선택 요약을 전달한다. 이메일은 보류 상태다.

## 갱신과 검증

원문을 다시 확인한 뒤 가격과 조건을 함께 갱신하고 catalog version을 올린다. 원문의 조건이 바뀌거나 사라지면 해당 선택을 보류한다. 자동 수집·자동 단가 갱신은 구현하지 않았다. 최근 부산 실거래 견적의 정확도 검증을 완료했다고 주장하지 않는다.

추가가 필요한 항목: 부산 현장 가격, 공개가격의 VAT 기준, 욕실 크기·철거 범위, 신발장·창호·필름의 검증 가능한 규격별 가격. 실제 DB 접수와 카카오 실수신은 운영 전 별도 검증한다.

## v3 · 추가 공사 범위
철거·폐기물, 전기·조명, 목공·몰딩, 방문·문틀, 발코니 타일, 현관 타일을 각각 유지/공사 없음·공사/교체 희망·상담 후 결정으로 기록한다. 확인된 공개 단가가 없으므로 금액을 만들거나 기존 소계에 더하지 않는다. 공사 희망·상담 항목만 pending에 포함하며, 전체 선택 상태는 scopeChoices와 상담 요약에 남긴다. 기존 v1/v2 입력에서 누락된 추가 항목은 공사 없음으로 호환한다. 욕실 패키지 등의 철거비를 재가산하지 않으며, 문 교체와 필름의 대상 중복은 상담에서 확인한다.
