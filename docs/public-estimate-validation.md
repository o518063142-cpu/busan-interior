## 카카오 알림과 전문 보존

- 공식 원본: https://developers.kakao.com/docs/ko/message-template/default 의 텍스트 템플릿 `text`는 최대 200자 표시다. 기존 긴 메시지의 실제 거부/누락 발생을 주장하지 않는다.
- 공간별 몰딩과 추가 요청을 포함한 긴 상담 전문은 알림 표시 한도를 넘으므로 전문 전체를 카카오 본문으로 보내지 않는다.
- 카카오에는 테스트 표시, 고객명·연락처·지역, 공개 참고 소계(총액 아님), 접수번호와 관리자 확인 안내를 우선한다. 공간·면적·일정과 일반 상담의 요청 미리보기는 남는 길이 안에서 표시한다.
- 메시지를 만들 때 원본 상담 데이터·추가 요청·견적 스냅샷을 변경하지 않는다. 전문은 기존 Firestore 저장과 관리자 상세 표시를 유지한다.
- 버튼은 허용된 기존 도메인의 `/admin` 경로로 고정한다. 로그인·기존 관리자 권한을 유지하며 개인정보를 URL에 넣지 않는다.
- 200자 이하에서 요약하며 긴 이름·지역에는 생략 표시를 남긴다. 테스트 접수의 고객 연락 금지 표시를 앞에 보존하고 이모지 surrogate pair를 자르지 않는다.

## 검증 범위

- 총 61개 테스트: 세 조합의 수기 합계와 서버 재계산 일치, 미확정 공사 보존, 전문 불변, 일반/장문/이모지/테스트 메시지 제한, 실제 알림 핸들러의 성공·실패 처리 포함.
- 공간별 몰딩의 거실·주방·복도·방별 구분, 부위·처리 방식·길이, 빈 길이 null, 유지/공간 해제·공사 상태 전환, 이전 선택 호환과 가격 합산 보류를 검증한다.
- API 테스트는 토큰·발송 HTTP를 모두 테스트 응답으로 대체한다. 실제 카카오 발송·새 상담 저장은 하지 않는다.
- PC1440/모바일390 브라우저에서도 실제 견적·알림 핸들러를 사용하고 Firestore와 카카오 외부 호출만 격리하여 검증한다. 긴 추가 요청 전문 보존, 200자 이내 알림, 소계·연락처·관리자 링크, 알림 실패 후 중복 저장 방지를 확인한다.
- Vite build, prerender, Express bundle 통과. tsc는 기존 미사용 `src/AIEstimatePage.tsx`의 import 3건만 실패한다.
- 작업은 기존 검토 브랜치/PR의 Preview 범위다. main 병합과 운영 배포는 하지 않는다.


## 공개 단가 참고 표시 검증
천장 교체의 도장 평몰딩, 걸레받이 교체의 PVC 예시, 기존 천장 몰딩 필름을 서로 다른 자료로 연결한다. 부가세 미확인/별도를 구분하며, 걸레받이 필름에는 직접 근거가 없음을 표시한다. 미입력 길이에도 단가 참고만 표시하고 길이를 입력해도 곱셈·평균값·소계 합산은 하지 않는다. 저장 스냅샷과 상담 전문에 별도 참고자료로 보존한다. PC·모바일에서 방식 변경 시 표시·출처 링크 교체, 유지/철거 시 참고 제거, 저장 후 자료 보존과 카카오 요약 200자 한도를 확인한다. 실제 카카오 알림은 추가 발송하지 않는다.


## 전기·철거 참고범위와 포함범위 확인
전체/부분/미확인 철거 구분과 욕실 전체철거 패키지 중복 안내를 검증한다. 전기 작업별 단위·자재 포함·별도 비용을 보존하고 전체 배선에 조명 가격을 대신 적용하지 않는다. 참고자료는 기존 소계와 actual priced sourceIds에 섞지 않는다. PC/모바일에서 작업 선택·해제, 공사 상태 전환 시 상세 초기화, 기존 소계 불변, 전체 상담 저장과 카카오 200자 요약을 외부 쓰기 없이 검증한다.


## 운영 반영 전 전환·인증 보완
새 선택형 화면은 첫 선택·상담 버튼·DB 저장 성공 이벤트를 명시적으로 기록하며, 기존 문구 관찰과 중복하지 않는다. 정상/차단된 브라우저 저장소에서 상담과 이벤트의 세션이 일치하는지 점검했다. 관리자 API의 CJS/ESM 로딩 오류는 jwks-rsa 하위 jose 호환 버전 고정으로 보완하고 실제 RSA 변환·검증을 로컬에서 확인했다. 상세 범위와 미검증 항목은 customer-estimate-release-review.md를 참조한다.


## v9 가구 화면·접수 흐름 검증 (2026-10-26)
- PC 1440px / 모바일 390px, React StrictMode에서 실제 선택 화면과 API 재계산을 검증. 신발장 길이 미입력은 합산 제외, 1.2m=720,000원/1.5m=900,000원, 싱크대 6m=6,000,000원. 마감 변경 차액 없음. 동일 신발장 필름 중복 방지·출처별 소계·상담 마감재/기준 저장 확인. 가로 넘침·페이지 오류 없음.
- 실제 DB와 카카오 외부 쓰기는 모의 처리. 저장 성공/실패·중복 제출·실패 알림 안내·공통 세션·성공 전환 이벤트를 검증했으며 실제 새 알림을 발송하지 않음. 모바일 저장소 차단 조건 통과. 도메인/접수 관련 테스트 40개, 인증/전환 테스트 5개 통과, Vite 빌드 통과.
